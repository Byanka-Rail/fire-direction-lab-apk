# FIRE DIRECTION LAB Android Updater

Single-WebView Android wrapper with GitHub-hosted HTML updates.

- Bundled game: `2.30.7.80`
- Update manifest: `https://raw.githubusercontent.com/Byanka-Rail/fire-direction-lab/main/update.json`
- Auto-check interval: 6 hours
- Manual update / rollback: Android Back button when the WebView has no back history
- One previous HTML build is kept as rollback
- Blob downloads are bridged to Android Downloads on Android 10+

For non-programmer build steps, open `BUILD_APK_초간단.txt`.
