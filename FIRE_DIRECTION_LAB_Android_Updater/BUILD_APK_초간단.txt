FIRE DIRECTION LAB Android APK — 가장 쉬운 빌드 방법
=====================================================

이 프로젝트는 프로그래밍을 몰라도 빌드할 수 있게 만들어져 있습니다.
게임 최초 내장판: v2.30.7.80
업데이트 저장소: Byanka-Rail/fire-direction-lab

[방법 A · PC에서 Android Studio]

1. Android Studio를 설치합니다.
2. 이 ZIP을 압축 해제합니다.
3. Android Studio → Open → FIRE_DIRECTION_LAB_Android_Updater 폴더를 고릅니다.
4. 처음 한 번 Gradle/Android SDK 다운로드가 끝날 때까지 기다립니다.
5. 위 메뉴에서 Build → Build Bundle(s) / APK(s) → Build APK(s)를 누릅니다.
6. 완료 알림의 Locate를 누릅니다.
7. app/build/outputs/apk/debug/app-debug.apk 가 설치용 APK입니다.

코드를 수정할 필요 없습니다.


[방법 B · GitHub가 대신 빌드 — 휴대폰에서도 가능]

1. GitHub에서 새 저장소를 하나 만듭니다. 예: fire-direction-lab-apk
2. 이 ZIP 안의 파일/폴더를 저장소에 그대로 올립니다.
   .github 폴더도 반드시 같이 올려야 합니다.
3. 저장소의 Actions 탭을 엽니다.
4. 왼쪽에서 "Build Android APK"를 선택합니다.
5. Run workflow → Run workflow 를 누릅니다.
6. 몇 분 뒤 완료된 실행을 누릅니다.
7. 아래 Artifacts의 "FIRE_DIRECTION_LAB_APK"를 받습니다.
8. 압축 안의 app-debug.apk가 설치용 APK입니다.

※ 이 방법의 debug APK 서명은 GitHub 빌드 환경에서 만들어집니다.
   HTML 게임 업데이트에는 APK 재빌드가 필요 없으므로 첫 설치용으로 쓰면 됩니다.


[앱 사용]

- 최초 설치에는 LAB v2.30.7.80이 들어 있습니다.
- 앱은 GitHub를 최대 6시간에 한 번 자동 확인합니다.
- 새 update.json build가 있으면 업데이트 창이 뜹니다.
- 즉시 확인하려면 Android 뒤로가기 → "업데이트 확인".
- 업데이트 후 문제가 있으면 Android 뒤로가기 → "이전 버전 복구".
- GitHub 접속 실패 시 내장/현재 버전이 그대로 실행됩니다.


[앞으로 LAB HTML 업데이트]

예: v2.30.7.81이 나왔을 때
1. Byanka-Rail/fire-direction-lab 에 새 HTML을 올립니다.
2. update.json의 version / build / file 만 새 버전으로 수정합니다.
3. Commit 합니다.
4. APK를 다시 만들 필요 없습니다.
5. 앱에서 업데이트 확인을 누르면 새 HTML을 받습니다.


[현재 update.json 형식]

{
  "version": "2.30.7.80",
  "build": 2300780,
  "file": "FIRE_DIRECTION_LAB_v2.30.7.80_수동확정잠금.html",
  "notes": "수동확정잠금 · 수정해 사전검증",
  "mandatory": false
}

file 값은 GitHub에 실제 올린 HTML 파일명과 정확히 같아야 합니다.


[내장 기능]

- WebView 게임 실행
- JavaScript / localStorage 유지
- GitHub update.json 자동 확인
- 새 HTML 다운로드/교체
- 다운로드 실패 시 기존판 유지
- 이전 HTML 1개 백업/복구
- JSON/TXT 내보내기를 Android Downloads/FIRE_DIRECTION_LAB 에 저장
- HTML 파일 입력창이 있으면 Android 파일 선택기 사용
- 별도 저장소 권한 요구 없음(Android 10+)
